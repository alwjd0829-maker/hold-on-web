# Build157 — 5회 무료 체험

- 기준: Build156 수익화 TestFlight 후보.
- 변경 범위: 고급 기능 진입 게이트만 국소 수정.
- Full Access 구매자는 기존처럼 즉시 고급 기능 사용.
- 미구매자는 고급 기능 진입을 통합 5회 무료로 사용.
- 무료 횟수는 UserDefaults에 누적되어 앱 재실행 후에도 유지.
- 무료 5회가 끝난 뒤에만 기존 `광고 보고 이번 한 번 사용` / `Full Access 한 번 구매` 화면 표시.
- 무료 사용 직후 남은 횟수를 짧은 토스트로 안내.
- 오디오+자막 편집 화면 진입 1회 = 무료 사용 1회. 영상 내보내기 실행 1회 = 무료 사용 1회. 편집 화면 내부의 무음 제거/음량/자막 조작을 각각 추가 차감하지 않음.
- 기본 기능(순간잡기, 저장, 저장 후 카메라, 카드 꾸미기, 오디오 파일 내보내기)은 기존처럼 무료.
- AdMob은 Build156과 동일하게 Google 공식 테스트 보상형 광고 ID 유지.
- 실제 기기 PASS는 별도 TestFlight 확인 필요.
